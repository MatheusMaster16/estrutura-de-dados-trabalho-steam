# estrutura-de-dados-trabalho-steam
Trabalho final referente a disciplina Estrutura de Dados, do segundo semestre do curso de Ciência de Dados na FATEC Jundiaí.

Dashboard para pesquisa de mercado de games independentes na plataforma Steam

O trabalho irá utilizar a API da plataforma Steam, da Valve, para criar um recurso de pesquisa de mercado, para auxiliar desenvolvedores independentes sobre lançamentos da plataforma.
